Debian / Ubuntu İstemci Bağlantısı

Bu deponun paketlerini kurmak isteyen istemci makinelerde aşağıdaki adımları uygulayın.

⚡

Tek Komutla Otomatik Kurulum (GPG + Depo)

Önerilen

İstemci makinenizde sadece şu tek satırı çalıştırarak GPG anahtarını ve depo listesini otomatik kurabilirsiniz:

curl -sSL http://localhost:8080/install.sh | sudo bash
🔑

GPG Anahtarını İndirin ve Doğrulayın (Güvenli Yöntem)

Resmi Debian standartlarına uygun olarak genel anahtarı /etc/apt/keyrings/ dizinine kaydedin:

sudo mkdir -p /etc/apt/keyrings && curl -fsSL http://localhost:8080/public.key | sudo gpg --dearmor --yes -o /etc/apt/keyrings/parslinux-archive-keyring.gpg
1

GPG İmzalı Depo Adresini Sources Listesine Ekleyin

İstemci makinede /etc/apt/sources.list.d/parslinux.list dosyasını oluşturun:

echo "deb [signed-by=/etc/apt/keyrings/parslinux-archive-keyring.gpg] http://localhost:8080/ bookworm main" | sudo tee /etc/apt/sources.list.d/parslinux.list
⚡

Alternatif: GPG'siz Test Kurulumu (trusted=yes)

Test ortamları için imza kontrolü olmadan hızlıca bağlanmak isterseniz:

echo "deb [trusted=yes] http://localhost:8080/ bookworm main" | sudo tee /etc/apt/sources.list.d/parslinux.list
2

Paket Listelerini Güncelleyin

Yeni eklenen deponun meta verilerini ve paket listesini çekin:

sudo apt update
3

İstediğiniz Paketi Kurun

Artık depodaki paketleri standart apt aracıyla kurabilirsiniz:

sudo apt install hello
